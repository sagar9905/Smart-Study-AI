# SmartStudy AI

SmartStudy AI is an AI-first adaptive learning and assessment platform built with the MERN stack. It is intentionally not a manual quiz CRUD app: assessments are generated by Google Gemini from topics, PDFs, or learner weakness data.

## Architecture

The backend uses clean separation:

- `controllers`: request and response orchestration only.
- `services`: business logic, Gemini prompts, Piston execution, analytics, adaptive generation, auth workflows.
- `models`: Mongoose schemas for users, assessments, questions, submissions, theory evaluations, and study plans.
- `routes`: Express route composition.
- `middleware`: auth, role authorization, validation, upload handling, security errors.
- `validators`: Zod request schemas.

The frontend uses:

- `pages`: route-level screens.
- `components`: reusable UI grouped by feature.
- `services`: Axios API clients.
- `context`: JWT auth state.
- `routes`: protected route guards.
- `layouts`: enterprise app shell.

## Required Environment

Backend:

- `MONGODB_URI`
- `JWT_SECRET`
- `CLIENT_URL`
- `GEMINI_API_KEY`
- `GEMINI_MODEL`
- `PISTON_API_URL`

Frontend:

- `VITE_API_URL`

## AI-Only Assessment Rule

There is no route, controller, or admin page for manually creating MCQs, subjective questions, or coding problems. Question creation happens only through Gemini-backed services.
